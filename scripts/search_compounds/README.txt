Example usage:
Rscript.exe .\search_compounds.R -i .\search_terms.txt -o output -a br:br08021,br:br08005

Required: 
'-i' or '--input' <input_file>
Required: 
'-o' or '--output' <output_folder>
Optional if you want to download compounds from brite categories: 
'-a' or '--append' <brite_categories> in the form 'br:br<number>,br:br<number>'
